ASTRA PHONE v5
================
Paper-trading simulator only.

NEW IN V5
- 1H / 4H / 1D market timeframe selector
- Multi-factor explainable analysis
- Risk-based position sizing
- Stop loss and take profit
- 2:1 planned reward/risk
- Automatic stop/target closing when refreshed market price crosses levels
- Daily loss lock
- Live open-position P/L
- Trade reason (STOP / TARGET / MANUAL)
- Portfolio stats

IMPORTANT
- No real orders are placed.
- No exchange API keys are used.
- Public GitHub Pages code must never contain private API keys.
- The analysis engine is rules-based, not a guarantee or financial advice.
- Background push alerts while the app is fully closed still require a push backend.

UPLOAD
Replace index.html, manifest.json, sw.js and the two icon PNGs with the files in this ZIP.
Wait 1–2 minutes after committing, then refresh your GitHub Pages site.
