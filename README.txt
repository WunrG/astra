ASTRA PHONE V1

This is a phone-first prototype. It is PAPER TRADING ONLY.
It does not connect to an exchange, place real orders, or use real API keys.

To use:
1. Put these files on a web host that gives you an HTTPS link.
2. Open the link on Android Chrome.
3. Use Chrome's menu -> Add to Home screen.

Next version can add a real market-data feed and an AI analysis backend.
